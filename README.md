# TRACK-DNF walker：HAIRPIN RUSH（网页 3D 小游戏）

AuNP walker 在 DNA 纳米花小星球上滚动，两分钟内尽可能多地打开发夹（H1）。第三人称跟随视角，方向键 / WASD 操作。

## 运行

在线玩（电脑、手机都行）：https://lywkx99.github.io/dnf-walker-web/

```
npm install
npm run dev
```

打开终端里显示的网址（默认 http://localhost:5173）。不联网也能用。本机 C 盘空间紧，安装时加 `--cache D:\C盘瘦身搬家目录\CodexTools\npm-cache`。发布网页见 `网站部署说明.md`。

### 在手机上玩（2026-10-15 加）

最简单是直接用手机打开上面的在线地址。下面是发布前在本机试的办法：

1. 手机和电脑连同一个 Wi-Fi。
2. 在本文件夹运行 `npm run phone`（先打包，再在局域网上开一个预览服务，端口 5300）。终端里 `Network:` 那一行就是手机要打开的网址，例如 http://192.168.1.120:5300 （电脑的局域网地址可能会变，以终端显示为准）。
3. 第一次运行时 Windows 可能弹出防火墙提示，要自己点“允许”（专用网络），否则手机连不上。
4. 手机浏览器打开那个网址，横过来玩（竖着拿会提示横过来）。
5. 改了代码要重新运行 `npm run phone`，它服务的是打包好的版本，不会自动刷新。

### 载入画面（2026-10-15 加）

第一次打开要等一会儿，载入画面先出来，不再黑屏。电脑上（GTX 1650）实测的时间分布：

| 阶段 | 耗时 |
| --- | --- |
| 从 GitHub 下载 1.8 MB 主脚本 | 约 0.8 秒 |
| 搭建 | 约 4 秒 |

搭建的 4 秒里，主线程被占住：
- 约 1 秒：星球表面约 26 万个顶点的地形计算；
- 约 3 秒：第一帧编译着色器。

手机上的搭建会更慢，网络慢时下载也会变长。

- 载入画面的样式和脚本直接写在 `index.html` 里，网页一到就显示（样式表也改成不阻塞首屏）。画面内容：标志、HAIRPIN RUSH、斜切分格的进度条、阶段文字、一条随机小提示。
- 进度条分三段：
  - 下载（0–70%）：按真实字节走，显示“DOWNLOADING · 0.8 / 1.8 MB”。打包时由 `vite.config.ts` 里的 boot-loader 插件，把主脚本的地址和大小写进页面；载入脚本先用 fetch 边下边报进度，下完再插入同一个地址的脚本。走浏览器缓存，不会下第二遍。
  - 搭建（70–95%）：显示“BUILDING THE PLANET”。这时主线程被占住，进度条交给浏览器自己的过渡动画继续往前走。
  - 收尾：3D 画面画出第 3 帧后，游戏调用 `__boot.done()`（`src/boot.ts`、App 里的 BootDone）：进度条走满，显示 READY，然后淡出。
- 脚本下载失败或搭建时出错，会显示“LOAD FAILED · TAP TO RETRY”，点一下重新载入。
- 开发模式（`npm run dev`）没有真实下载进度，进度条会慢慢往前爬。

### 全屏

- 右上角（手机上在左上标志下面）的四角按钮，或 F 键：进入 / 退出全屏。安卓手机上全屏时顺便锁成横屏。
- iPhone 的 Safari 不允许网页自己全屏，点按钮会提示：点“分享”→“添加到主屏幕”，再从主屏幕的图标打开，就没有地址栏了（页面里已经写好了需要的设置）。

## 怎么玩（2026-10-14 第七版）

- **开始界面**：三步引导，顶部是可以点击的步骤条（当前一步金色，走过的绿色）。Enter / 空格 / → 下一步，← / Backspace 上一步，第一步可以 SKIP 直接跳到选轨道。看过一次以后，从结算界面回来直接停在第 3 步。
  1. THE RUSH：游戏名、目标（两分钟内打开尽量多的发夹），一张“烧掉的桥”示意图——身后打开过的发夹是青绿色的、没用了，身前没用过的是红色的、每个 +1，walker 在中间往前冲。配一句说明“每个发夹只能打开一次，身后的路是烧掉的，只能一直冲向新的轨道”，这是 RUSH 的本质。下面三个小标签：+1 每个发夹、2:00 计时、方向键操作。
  2. THE ROAD AHEAD（2026-10-15 按反馈改）：标题“WHAT YOU'LL FACE”（你会遇到什么），提示“没有标识牌，要认形状”。两个并排的模块，各自是切角框加发光描边：
     - 左边 POWER：绿色，闪电徽章，标签“GRAB THESE”，标题栏是斜向光纹。内含冲刺台、砸地、H2 燃料。
     - 右边 DANGER：红色，警告徽章，标签“STEER CLEAR”，标题栏是黄色警示斜条。内含自陷区（纳米花折叠区）、吸附井、晶体柱。
     - 模块标题是大号斜体渐变字带发光。每一项一行：六边形图标、名字、效果标签、一句短说明。竖屏窄屏时两个模块上下排。
  3. THE TRACK：三张切角竖卡，标题是 LT-DNF / MT-DNF / HT-DNF，配密度点阵、低 / 中 / 高密度、一句性格、抓地和钉住（PIN）两条 5 格示意条（表达性格，不是测量值）和最佳成绩。1 / 2 / 3 或点击选择，按钮写“START HT-DNF”这样的完整轨道名。
- **一局**：倒计时 3、2、1、GO，然后两分钟。上方正中是计时（最后 10 秒变红闪烁），右下仪表的发夹数就是得分。
  - 局中操作：↑↓ 前进后退，←→ 转向（空中也能转，用来躲落点的障碍），R 重开，Esc 回开始界面，M 开关声音，F 全屏。
  - 触屏（手机 / 平板，自动识别）：左下两个圆键左右转向，右下 BRAKE / GAS 两块踏板。踏板做成赛车金属踏板的样子：带色调的拉丝金属板，有高光和厚度；中间凹进去一块冲孔防滑面；上面一个图标（油门双箭头、刹车用仪表上的刹车标志），底下一块铭牌。按下时踏板往前压，冲孔亮起，铭牌反色。按住生效，可以多指同时按（一边转一边踩油门），手指滑出按钮也算按着。被粘住时按住 GAS 挣脱。比赛中左上多一个 ≡ 按钮回菜单。
  - 手机版面：仪表缩小放右上，计时缩小，按键提示隐藏，按钮上的按键标记去掉；开始 / 结算界面在矮屏上再压紧一档，步骤条和“下一步 / 再来”按钮一直看得见，内容多时中间可以滑；默认流畅画质、渲染分辨率 1 倍，省电。
  - iPhone 不全屏也能玩（2026-10-15 补）：Safari 横屏、地址栏还在时，看得见的高度只有约 320–350。为此做了三件事：
    - 面板高度改用 dvh：Safari 的 100vh 算上了地址栏后面的部分，原来面板会上下被切掉。
    - 高度 350 以下再压一档：标题、示意图、按钮和触屏按键都小一号。
    - 补上字体：iPhone 没有 Bahnschrift，原来退到没有窄体的系统字，字变宽、被挤出界面。现在随网页打包 Saira 可变字体（`@fontsource-variable/saira`，宽窄轴 50–125%），没有 Bahnschrift 的设备自动用它；Windows 上照旧用 Bahnschrift，也不会去下载它。
    - 在 844×340（iPhone 14 一类）和 667×320（iPhone SE 一类）下检查过：三步引导、比赛界面、结算页都完整。
  - 竖着拿时提示横过来，并提醒“转不过来就在控制中心关掉竖排方向锁定”。
- **得分**：打开的发夹数 + 砸地震开的发夹 − 撞车扣分。
  - 砸地（第七版补充）：腾空超过 0.5 秒落地时，冲击波把落点周围一圈还没用过的发夹直接震开。冲击圈半径 = 0.8 + 0.35 × 跃升高度 + 0.06 × 飞行距离，最大 5.5。冲刺台跳一次一般跃升约 3–5、飞出约 10–17、半径约 2.5–3.7，平均震开：低密度约 8、中密度约 26、高密度约 12 个（高密度落地常在自陷状态里）。强调方式：两道金色冲击环扩到冲击圈大小，被震开的发夹闪金光再褪成青绿，镜头重重一震，屏幕中间弹出金色“SLAM +N”（下面标跃升高度和飞行距离），里程旁弹出金色大号 +N，并播放重击加街机式加分音效。
  - 撞车：以超过 1 的速度撞上晶体柱扣 30 分（1 秒内不重复扣）。屏幕中间红色“CRASH −30”左右一抖，里程往回滚，并播放撞车声。轻轻擦到只播 IMPACT，不扣分。
- **结算**：标题写“TIME UP · 轨道名（如 MT-DNF）”，得分滚动显示、评级（S / A / B / C / D，按这条赛道参考成绩的倍数算）、最佳成绩（存在浏览器本地；浏览器不让存时只在本次打开期间有效）。另外列出八项统计（最高速度、最长腾空、最佳砸地、撞车次数、冲刺台次数、H2 燃料、被卡住秒数、被粘住秒数）和本局学到的 walking 小知识。
- **音效**（`src/sfx.ts`，全部用 Web Audio 现场合成，不加载音频文件，风格是赛车游戏）：
  - 引擎（开动时一直在响）：转速跟车速走，分 5 档，每档里转速一路拉高，升档时转速往下一掉并“噗”一声泄压。踩油门更响更亮；腾空时空转拉高；被粘住踩油门时转速拉满但声音发闷。音量压得比较低；静止时完全没有声音（没有怠速），松油门滑行时越慢越轻，比赛外淡出。
  - 风噪随速度变大（空中更明显）；打滑时轮胎尖叫；冲刺台加速、惯性保留、H2 加速时有涡轮哨音。
  - 一次性的声音：打开发夹是短促的电子提示音（连续打开一点点升调）；冲刺台是涡轮增压；捡 H2 是氮气喷射（“嗤——”加一下闷推）；起跳悬挂一松；落地悬挂砸底（越重越沉，重的带金属碰撞）；砸地是重击加街机式加分音效（震开越多越长）；撞晶体是撞车声（碎裂加金属泛音）；被粘满“咕咚”一声陷进去；挣断黏丝“咔”；挣脱时轮胎尖叫加闷推。
  - 界面：起跑三声短低音加一声长高音；最后 10 秒每秒一声警示音；时间到两声终点喇叭；破纪录播胜利号角；菜单按钮有选择提示音。
  - 浏览器要求先有一次操作才能出声，所以第一次按键或点击时才启用（手机上手指按下不算，抬起才算，所以第一次点完按钮以后才有声音；iPhone 静音键打开时也没有声音）。页面切到后台时自动暂停；另外只要画面停止刷新超过 0.3 秒（比如面板被隐藏），引擎、风噪这些持续的声音就自动淡出，不会一直响。右上角喇叭按钮或 M 键静音，选择会记在浏览器本地。
- **walking 小知识**：每局第一次遇到某种情况时，左上方弹出一张卡片，结算时汇总。
  - 卡片是游戏里“解锁图鉴”的样子（2026-10-15 按反馈去掉了左边一条色线的普通框）：切角面板，渐变发光描边，淡扫描线。
  - 卡片内容：左边六边形徽章放对应图标；顶上“NEW WALKING NOTE”和收集进度（如 03/08）；大号斜体标题，扫过一道高光，下面一条带色块的分隔线；正文里的关键词用强调色（在 `src/hud.ts` 的 LESSONS 里用 `*...*` 标）；底边一条倒计时条。
  - 出场：从中线上下展开。结算里的知识卡是同一套样式的缩小版。
  - 共八条：共八条：SIGNAL（H1 被打开、H2 置换腿 = 信号）、MULTIVALENT GRIP（多条腿同时结合）、TOO FEW LEGS（太稀打滑）、SELF-TRAP（纳米花表面是折叠的，在狭窄、产物拥挤的折缝里颗粒被物理卡住，周转变慢的候选原因之一）、PINNED（同时结合的腿太多，walker 被钉在原地）、BURNT BRIDGE（打开过的发夹不能再用）、NON-SPECIFIC ADSORPTION（颗粒粘在表面上不走）、H2 FUEL（燃料多、置换快、走得快）。
- **地形与障碍**：
  - 冲刺台：约 27 个。坡面上额外加速（最高到常态最快速度的 1.25 倍，播报 BOOST）；冲出坡顶时额外向上、向前推一把。第七版后期按“太简单”的反馈调低了：坡面加速、上限和前冲都减小。
  - 冲刺台落地后的惯性保留：保留 5 秒。期间超出常态的速度每秒掉 0.8；悬挂沿竖直方向托住，落地和上坡不吃掉前进速度；离地时往下压，让球贴地掠过；腿的置换至少加快到 1.3 倍、高于常态速度时按车速同比加快；在自陷区外不累积自陷；身后拖一道青色尾迹。松油门、被粘住、进入自陷区或撞柱会提前结束。
  - 落点障碍：游戏启动时，用同一套物理从每个冲刺台全速冲一次，算出落点，在落点轮流放三根晶体柱摆成的楔形、自陷区或吸附井（目前 16 处）。出生点正前方第一个冲刺台不放，第一跳干净利落。
  - 自陷区（折叠区）：纳米花折叠出的崎岖沟槽，拓扑受限、产物富集（位点加密到约 3 倍）。贴地进去就会被物理卡住（状态显示 TRAPPED），跟腿数和速度都无关；进去就打断惯性保留，卡住时腿额外刹车，在区里还有额外阻力，所以高速也冲不过去。出来以后要好几秒才慢慢恢复。地面有一圈红色虚线，不立标识牌。
  - 吸附井（非特异性吸附）：
    - 地形：一个光滑的碗，靠近会被往中心吸。
    - 被粘住：在井里贴地（或贴着井面低空掠过）会慢慢沾上，沾到一定程度、或者冲进井中心那一圈（半径的 55% 以内），黏丝一下子粘满（播报 ADSORBED、状态 STUCK）。这时腿不再被置换，也不出信号。吸力也比之前大，从井边擦过会被往里拽。
    - 挣脱：按住 ↑ 一根根挣断黏丝，每断一根往前一冲，大约 3 秒挣脱（播报 BREAK FREE）。挣脱后 3 秒内不会再被粘，吸力也减弱，用来滚出去。只有飞得够高才越得过去。
    - 画面：井面是一层凝胶，有往中心流的同心波纹和旋进去的螺旋流线；中心有一个往下旋的光漏斗；光点从井沿高处盘旋着被吸进去。被粘住时，酸绿色黏丝从球侧拉到地面，挣扎时被拉长变细，断开时溅出黏液；球面裹一层黏液。屏幕下方显示“HOLD ▲ TO BREAK FREE”和剩下几根黏丝。井边一圈酸绿色虚线，不立标识牌。
  - H2 燃料：22 个漂浮的电光蓝双螺旋。碰到就捡起（播报 H2 BOOST）：那一下往前推一把（+0.35 倍常态最快速度），之后 8 秒里能跑到的速度 ×1.25、腿的置换 ×1.8，限速放宽，身后拖一道蓝色尾迹，仪表上方有倒计时条。25 秒后重新长出来。燃料链越多、腿被置换得越快、walker 走得越快，这一点和真实的 DNA walker 一致；具体倍数是游戏设定。
  - 另有陨坑、晶体柱、丘陵山脊。
- **速度**：常态最快速度从 9.5 提到 12。仪表按实际速度显示（每单位 ×24，刻度 0–480）：中密度在新路上常态约 180，全速约 290，冲刺台和惯性保留时进入红区。打滑时只是慢慢减速（每秒 1.5），靠惯性滑过去。
- **防卡死**：周围的发夹都用完了（“烧掉的桥”）时，悬挂改为沿竖直方向，球能翻出陡坡，不会困死在自陷区的鼓包或坑里。
- 不立标识牌：自陷区和吸附井只靠地形和地面虚线辨认（第七版后期按反馈去掉了牌子）。

## 规则（示意模型，不是定量模拟）

- 腿只能和够得到的、还没用过的 H1 结合；结合一段时间后 H2 把腿置换下来，这个 H1 被打开（变绿 = 示意信号），不能再用。
- 速度由“同时结合的腿数”决定：太少会打滑；适中最快；太多（≥ 9 条）会逐渐被钉住（状态显示 PINNED，对应稿件里“多条腿同时成双链造成的固定”）。被卡住 / 钉住时驱动打折（×(1 − 0.6×程度)），腿额外刹车（3 + 6×程度），置换也变慢（×(1 − 0.8×程度)）。置换变慢是这个模型自己的假设：颗粒动不了，H2 也不容易把腿置换下来。没有这一条，原地卡住的球会在加密的折叠区里不停点亮，变成刷分点。
- 三档密度对应稿件的低 / 中 / 高密度轨道（锚定间隔 85 / 53 / 27 nt），画面里位点间距按比例取。
- 自陷的解读（第七版后期按作者说明改正）：自陷是 walker 在折叠纳米花里被物理卡住，发生在拓扑受限、产物富集的折叠区域，不是“腿太多”。稿件把这几种都列为周转变慢的候选界面限制，没有定论：静电排斥、非特异性相互作用、多条腿同时成双链造成的固定、产物富集或拓扑受限区域的自陷。游戏里的对应：折叠区 = 自陷（TRAPPED），腿太多 = 被钉住（PINNED），吸附井 = 非特异性相互作用（STUCK）。“折叠区里不管腿数、不管速度都会卡住”是游戏设定。H2 燃料、冲刺台、惯性保留、砸地都是游戏化的示意，不是稿件里的结果。walker 的运动方式（滚动或步进）稿件未测定，滚动只是示意（可在“设置”里关掉）。
- 各档密度的得分高低不刻意调成“中密度最好”。

## 离线模拟

`node sim.ts` 不开浏览器把三档密度各跑一遍，大约 1–2 分钟。第七版最终参数的结果：

- 缓弯 4 个朝向 × 30 秒（平均速度占常态最快速度）：低 36%，中 55%，高 48%。
- 冲刺台净收益（同一起点带着常态速度冲 20 秒，对比转开 90° 不冲；空中按最近障碍的另一侧躲）：
  - 落点没障碍的 12 个：低 +29%，中 +29%，高 +30%。
  - 落点有障碍的 15 个：低 +19%，中 +10%，高 +20%。
  - 样本少、路线各不相同，单项波动在 ±15% 左右。
- 高速冲障碍（带着 1.3 倍常态速度冲向中心、按住前进）：吸附井 9 口里被粘住 7–9 次（低 / 中 / 高），挣脱平均 3.2–3.6 秒、最长 4 秒；自陷区 10 片里被卡住 9–10 次，穿过平均 3.8–9 秒（最长 14 秒），出来时速度只剩约 30%。都没有卡死的。
- 两分钟一局（会找新路的 AI，3 个出发朝向平均；算上砸地和撞车扣分）：低约 530，中约 1570，高约 1390。这就是结算评级用的参考成绩（`src/hud.ts` 里的 PAR）。这个 AI 很少主动去冲冲刺台，会冲冲刺台、会躲障碍的玩家应该能明显超过。
- 冲刺台测试里的砸地：平均每次震开 低约 8、中约 26、高约 12 个。

## 调试

网址后面加 `?touch`（例如 http://localhost:5173/?touch）可以在电脑上强制用手机版面。浏览器的手机模拟在宽度 768 以上不算触屏设备，测 iPhone 横屏尺寸时要靠它。

浏览器控制台里：

- `__dnf.goTrapZone(k)` / `goWell(k)` / `goCrystal(k)`：把 walker 放到第 k 片自陷区 / 第 k 口吸附井 / 第 k 根晶体柱跟前，面朝它。
- `__sfx`：音效模块（例如 `__sfx.ctx.state` 看声音有没有启用）。
- `__hud`：界面读的实时状态。
- `__game`：这一局的状态，例如 `__game.count = 0` 跳过倒计时，`__game.t = 1` 快进到结算。
